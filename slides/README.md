# Pure Scala FP — slides

1-hour beginner course (Slidev) introducing every concept used in the `pure-scala-fp` exercises.
Examples deliberately use other data (books, logs, numbers) so they never give away the solutions.

```bash
npm install
npm run dev      # present at http://localhost:3030 (press `p` for presenter mode with notes)
npm run build    # static site in dist/
npm run export   # slides-export.pdf (uses playwright-chromium)
```
